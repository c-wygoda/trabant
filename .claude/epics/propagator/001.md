# Task: TLE/OMM Parser

## Description
Implement parsers for Two-Line Element (TLE) sets and Orbital Mean-elements Message (OMM) formats. Extract orbital elements with full validation according to NORAD standards, handling both standard and edge cases.

## Acceptance Criteria
- [ ] Parse standard TLE format with checksum validation
- [ ] Parse OMM/XML format from fixture file
- [ ] Extract all orbital elements (epoch, mean motion, eccentricity, inclination, RAAN, argument of perigee, mean anomaly, B* drag)
- [ ] Validate element ranges and consistency
- [ ] Handle edge cases (high eccentricity, negative B*)
- [ ] Return structured orbital elements ready for SGP4

## Technical Details
- Create `src/sgp4/tle.rs` for TLE parser
- Create `src/sgp4/omm.rs` for OMM parser
- Create `src/sgp4/elements.rs` for common orbital element structure
- Use nom or manual parsing for TLE format
- Use serde for OMM/JSON parsing
- Implement checksum algorithm for TLE validation
