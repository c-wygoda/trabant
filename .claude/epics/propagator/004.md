# Task: Coordinate Transformations

## Description
Implement coordinate frame transformations from TEME (SGP4 output) to GCRS (inertial) and ITRS (Earth-fixed). Use EOP data for accurate Earth orientation.

## Acceptance Criteria
- [ ] TEME to GCRS transformation (precession, nutation)
- [ ] GCRS to ITRS transformation (Earth rotation, polar motion)
- [ ] Use EOP data for polar motion and UT1-UTC
- [ ] Matrix operations optimized for performance
- [ ] Match skyfield GCRS/ITRS positions within 10 meters
- [ ] Handle position and velocity vectors

## Technical Details
- Create `src/coordinates/mod.rs` for transformations
- Create `src/coordinates/teme_to_gcrs.rs` for precession/nutation
- Create `src/coordinates/gcrs_to_itrs.rs` for Earth rotation
- Create `src/coordinates/matrix.rs` for 3x3 matrix operations
- Implement IAU 2000A/2006 nutation model
- Use GMST/GAST for sidereal time calculations
