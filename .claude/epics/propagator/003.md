# Task: EOP Data Handler

## Description
Parse and manage Earth Orientation Parameters (EOP) from IERS CSV format. Implement efficient lookup and linear interpolation for dates between published values.

## Acceptance Criteria
- [ ] Parse EOP CSV file from tests/fixtures/eop.csv
- [ ] Extract polar motion (x, y), UT1-UTC, LOD values
- [ ] Implement linear interpolation between dates
- [ ] Return error for dates outside EOP range
- [ ] Cache parsed data for performance
- [ ] Provide lookup by Julian date

## Technical Details
- Create `src/eop/mod.rs` for EOP handling
- Create `src/eop/parser.rs` for CSV parsing
- Create `src/eop/interpolation.rs` for date interpolation
- Use BTreeMap for efficient date-based lookup
- Store as singleton or pass through context
- Consider memory-mapped file for large datasets
